# **App Name**: Pockets

## Core Features:

- User Authentication: Secure signup and login using Firebase Auth (email/password and Google).
- Monthly Budget Setup: Set and edit a monthly budget in BDT.
- Expense Tracking: Record daily expenses with categories, notes, and dates, stored in Firestore.
- Remaining Balance Indicator: Calculate and display remaining money after deducting expenses from the monthly budget.
- Daily Limit Enforcement: Optionally enable and set a daily spending limit, with warnings for exceeding the limit.
- Dashboard Visualization: Display total expenses, remaining money, daily limit progress, and expense breakdowns via bar and pie charts.
- Monthly Report Generation: Generate a downloadable PDF summary of monthly expenses and remaining balance.
- Multi-language Support: Switch between English and Bangla, updating all UI elements and messages.

## Style Guidelines:

- Primary color: Violet-indigo (#6752FF) for a modern and interactive feel.
- Secondary color: Soft sky blue (#7DD3FC) to complement the primary.
- Alert/Highlight color: Light yellow (#FDE047) for important notifications.
- Background color: Off-white clean (#F9FAFB) for a minimal look.
- Text color: Dark slate (#0F172A) for readability.
- Body and headline font: 'Inter' sans-serif with headings at weight 600 and body at weight 400.
- Use clean and modern icons relevant to each expense category.
- Minimal layout with a focus on clarity and intuitive user experience.
- Soft shadows, rounded corners, and subtle hover effects for interactive elements.
